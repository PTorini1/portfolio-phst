# Spec 02 — Design System

## Objetivo
Criar uma base visual consistente antes das páginas.

## Definir
- Tipografia.
- Escala de headings.
- Cores para light/dark.
- Backgrounds.
- Texto primário/secundário.
- Bordas.
- Espaçamentos.
- Breakpoints.
- Container principal.
- Estados de hover/focus/active.

## Componentes base
Criar apenas componentes realmente reutilizáveis:
- Button/Link visual.
- Container.
- Section.
- Badge/Tag.
- ExternalLink.
- ThemeToggle.

## Direção
Visual inspirado em portfolios técnicos modernos: bastante espaço, boa tipografia e hierarquia clara.

Evitar:
- excesso de cards;
- gradientes decorativos;
- animações excessivas;
- sombras pesadas.

## Critérios de aceite
Todas as páginas futuras devem conseguir reutilizar tokens e componentes base sem criar estilos conflitantes.
