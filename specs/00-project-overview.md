# Portfolio Pessoal — Visão Geral

## Objetivo
Criar um portfolio profissional de Pedro Torini, com foco em experiência como desenvolvedor .NET/backend e um blog técnico baseado em Markdown.

O site deve comunicar experiência prática, projetos, tecnologias e capacidade de explicar problemas reais e suas soluções.

## Stack inicial
- React
- TypeScript
- Vite
- React Router
- Markdown
- CSS moderno ou Tailwind CSS

## Fora do escopo inicial
- Backend
- Banco de dados
- API própria
- Autenticação
- CMS
- Área administrativa

## Idiomas
- Português brasileiro (`pt-BR`)
- Inglês (`en-US`)

## Conteúdo
Experiência, habilidades e projetos devem ficar separados da camada visual. Artigos devem ser arquivos Markdown com frontmatter.

## Referência visual
Usar https://aakashrajbanshi.com.np/ apenas como inspiração de estrutura, ritmo visual e simplicidade. Não copiar identidade, código ou conteúdo.

## Princípios
- minimalista
- profissional
- responsivo
- acessível
- rápido
- SEO-friendly
- fácil de manter
- sem overengineering

## Critérios gerais
- `npm run build` deve funcionar sem erros.
- Não introduzir backend nesta fase.
- Não colocar conteúdo profissional diretamente em componentes quando ele puder ser representado por dados.
- Componentes devem ser reutilizáveis e semanticamente corretos.
