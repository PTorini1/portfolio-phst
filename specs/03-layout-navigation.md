# Spec 03 — Layout e Navegação

## Objetivo
Criar a estrutura global do site.

## Rotas
- `/`
- `/about`
- `/experience`
- `/skills`
- `/projects`
- `/blog`
- `/blog/:slug`
- `/contact`

## Header
Desktop:
- nome/logo textual;
- navegação;
- seletor PT/EN;
- theme toggle.

Mobile:
- menu acessível;
- navegação fechando após seleção.

## Footer
Incluir:
- nome;
- copyright;
- LinkedIn;
- GitHub;
- email.

## Critérios de aceite
- Todas as rotas funcionam.
- Links internos usam routing apropriado.
- Links externos são identificados como externos.
- Navegação funciona por teclado.
- Layout não causa overflow horizontal.
