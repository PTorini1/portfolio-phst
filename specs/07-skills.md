# Spec 07 — Habilidades

## Objetivo
Apresentar tecnologias de maneira organizada.

## Categorias iniciais

### Backend
C#, .NET, ASP.NET Core, ASP.NET MVC, Web APIs, Dapper, Entity Framework Core.

### Cloud
Microsoft Azure, Azure Service Bus, Azure Functions, Azure SignalR, Azure Cache for Redis, Azure SQL, Azure OpenAI.

### Banco
SQL Server, Redis.

### DevOps/Infra
Docker, Docker Compose, Kubernetes, GitHub Actions, Azure DevOps.

### Observabilidade
Serilog, OpenTelemetry, Prometheus, Grafana, Loki, Application Insights.

### Outros
Git, REST APIs, mensageria, arquitetura orientada a eventos, RPA, integração com IA.

## Apresentação
Evitar transformar todas as skills em grandes cards.

Usar categorias, tags ou lista visual limpa.

## Critérios de aceite
Skills devem ser dados configuráveis e facilmente traduzíveis quando necessário.
