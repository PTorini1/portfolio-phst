# Spec 11 — Internacionalização

## Objetivo
Suportar PT-BR e EN-US desde a primeira versão.

## Idiomas
- `pt-BR`
- `en-US`

## UI
Textos da interface devem ficar em arquivos de tradução, não espalhados pelos componentes.

## Blog
Cada idioma possui seus próprios arquivos Markdown.

Sugestão:
```text
content/posts/pt-BR/
content/posts/en-US/
```

## Comportamento
- Detectar idioma do navegador inicialmente.
- Permitir troca manual.
- Persistir escolha no localStorage.
- Não traduzir artigos automaticamente.

## Critérios de aceite
Trocar idioma altera navegação e conteúdo institucional sem reload completo desnecessário.
