## Regra para o Codex

Antes de implementar uma spec:
- leia `00-project-overview.md`;
- leia a spec atual;
- inspecione o estado atual do projeto;
- preserve decisões já implementadas;
- não implemente funcionalidades de specs futuras;
- execute testes/build/lint relevantes ao terminar;
- corrija regressões antes de considerar a spec concluída.

O backend está explicitamente fora do escopo desta versão.
