# Spec 06 — Experiência

## Objetivo
Apresentar a trajetória profissional em formato de timeline ou lista visual.

## Dados
Cada experiência deve suportar:
- empresa;
- cargo;
- período;
- descrição;
- responsabilidades;
- tecnologias.

## Estrutura sugerida
```text
Cargo
Empresa · período

Descrição curta

• responsabilidade
• responsabilidade

Tecnologias: C#, .NET, SQL Server...
```

## Regras
Dados devem ficar fora dos componentes.

Criar estrutura tipada para experiências.

## Critérios de aceite
Adicionar uma nova experiência deve exigir apenas alteração nos dados, sem duplicar markup.
