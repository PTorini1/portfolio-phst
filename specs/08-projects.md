# Spec 08 — Projetos

## Objetivo
Apresentar projetos relevantes com foco no problema e na solução.

## Dados de cada projeto
- título;
- descrição;
- tecnologias;
- imagem opcional;
- GitHub;
- demo;
- artigo relacionado.

## Projetos iniciais
1. Sistema de notificações assíncronas.
2. Observabilidade para aplicações .NET.
3. Solução de RPA para matrícula de mais de 60 mil alunos.
4. Outros projetos que forem adicionados posteriormente.

## Direção
A descrição deve explicar impacto e contexto técnico, evitando apenas listar tecnologias.

## Critérios de aceite
Projetos ficam em arquivo de dados separado e podem ser destacados na Home.
