# Spec 01 — Project Setup

## Objetivo
Criar a base React + TypeScript + Vite do portfolio.

## Implementar
- Inicializar projeto Vite.
- Configurar TypeScript.
- Configurar React Router.
- Configurar lint e formatter se necessário.
- Criar scripts `dev`, `build`, `preview` e `lint`.
- Criar estrutura inicial:

```text
src/
├── components/
├── layouts/
├── pages/
├── content/
├── data/
├── hooks/
├── i18n/
├── lib/
├── styles/
├── types/
├── App.tsx
└── main.tsx
```

## Regras
Não instalar bibliotecas sem necessidade clara.

## Critérios de aceite
- Aplicação inicia localmente.
- Build de produção funciona.
- TypeScript sem erros.
- Estrutura preparada para as próximas specs.
